# Overview
The tracertools package is a collection of Python functions designed to streamline common tasks for connectomics researchers, particularly those related to the proofreading process.

Full documentation including [installation instructions](https://github.com/jaybgager/tracertools/wiki), [function descriptions and examples](https://github.com/jaybgager/tracertools/wiki#function-summaries), and a [glossary of terms](https://github.com/jaybgager/tracertools/wiki/glossary) can be found on the [official wiki](https://github.com/jaybgager/tracertools/wiki).
